# 貨品資料與實際驗收流程

## 第一次建立資料

登入網站後按「管理貨品 · 新增／匯入」。沒有表格也可以使用：按「＋ 新增貨品」，填貨號及名稱，庫存、單位、型號、存放位置和檢查紀錄按需要填寫。按「儲存貨品」，看到「已儲存」才代表完成。

貨號必須與實物條碼內容一致；其他可接受的條碼可填在「其他條碼」，以 `|` 分隔。未知庫存留空，不能用 0 代替未知數量。

## 從已有 Excel 匯入

1. 在 Excel 或 Google 試算表選取貨品資料，**連同第一列欄名一起複製**。
2. 開啟「匯入／貼上表格」，貼上後按「讀取貼上的表格」。
3. 選擇「貨號／條碼」與「名稱」對應哪一欄。常見中文及英文欄名會自動配對，其他欄位可選擇不匯入。
4. 按「2. 預覽匯入結果」。核對貨號、名稱、庫存、單位、位置及新增／更新筆數。
5. 按「3. 確認並儲存到我的帳戶」，看到「已儲存」後可關閉頁面。
6. 用同帳戶重新登入或開啟網站，貨品仍在。已開啟的其他頁面可按「重新讀取」取得更新。

若喜歡選取檔案，在 Excel「另存新檔」選 **CSV UTF-8（逗號分隔）**，再使用頁面的檔案選取器。也接受 TSV、文字表格及完整 JSON 備份；不直接讀取 `.xlsx`／`.xls` 活頁簿。

| 貨號 | 名稱 | 庫存 | 單位 | 存放位置 |
| --- | --- | --- | --- | --- |
| A102 | 輸送帶馬達 | 3 | 台 | A-03 |
| BOX-001 | 電子零件貨箱 | 12 | 箱 | B-01 |

此表是格式範例，請改成你的實際資料。最少只需貨號及名稱。庫存須為非負整數；欄位不填單位或千位逗號。含前置 0 的貨號在 Excel 須設為文字，避免 Excel 在複製前已刪去 0。最多 200 筆，每個檔案小於 250 KB；完整帳戶資料儲存上限為 140 KB，太長的歷史紀錄可先備份整理。

同貨號會更新已對應欄位，**該欄留空也會覆蓋原值**。未對應欄位、其他貨品保留。重複货號、其他條碼撞號或格式錯誤會阻止匯入。成功儲存後，在同頁可「復原上次儲存」；離開前可下載 CSV 或 JSON 備份。另一頁已修改時會拒絕舊版本覆寫，請先保留待匯入的原始表格，再重新讀取和預覽。

## 每次工作

1. 「巡檢紀錄」→「開始新驗收紀錄」，避免沿用上一箱的勾選。
2. 選擇貨品 →「設為預期貨號」→ 開啟鏡頭或載入驗收照片 → 貨號模式掃描實物條碼／QR。
3. 有遠端同事時建立房間，分享完整房間連結。對方免登入按「加入房間」，切到「夥伴視角」查看現場。
4. 以箭頭、圈選、畫線及文字指出檢查位置。固定實物的需求才用 Android WebXR AR，由現場確認平面及位置。
5. 人工核對貨號、外箱、封口及數量，填備註，再勾選清單。AI 損傷結果只是疑似範圍，仍需人確認。
6. 按「儲存驗收紀錄」，確認成功後可從同帳戶再次開啟。下載「驗收摘要 CSV」交接；完整座標及詳細資料用 JSON 備份。照片不存到雲端，另按「擷取畫面」留證。
7. 庫存有變化時，回到貨品管理按「編輯」，填入新的總數並新增檢查紀錄。掃描和完成驗收不會自動增減庫存。
8. 結束房間，關閉鏡頭與收音。

## 資料範圍

正式貨品和驗收紀錄按帳戶隔離。受邀訪客可以影音／標記協作，不能讀取或修改你的貨品庫；遠端掃描內容同步後，登入者按自己的貨品資料核對。AI 名稱標籤可能隨已開啟的標記畫面分享，分享前請確認畫面內容。

練習模式在「管理貨品」→「練習與備份」中開啟，只讀取虛構範例，不寫入正式資料。返回我的貨品即可結束。
