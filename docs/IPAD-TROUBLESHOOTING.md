# iPad 物件／人臉分析

本專案的空間 AR 使用 Android 相容裝置的 Wonderland / WebXR。網站不提供 iPad 定位圖 AR；以下僅說明一般鏡頭的物件／人臉分析。

若切換「物件」後看到 `Can't find available document`、`document is not defined` 或 OffscreenCanvas 錯誤，通常是影像分析執行環境問題，與匯入貨品表格或登入金鑰無關。

Apple 行動裝置（包括以 Mac 身份顯示網頁的 iPad）使用網頁內 HTML Canvas 和 CPU 執行物件／人臉模型，避開 MediaPipe 在背景執行緒中要求 DOM 的路徑。影像仍在本機分析。其他裝置保留背景執行緒；若出現繪圖環境錯誤會再試網頁相容路徑。相容路徑最多使用 640 像素寬影像，分析完成後間隔 700ms 再處理下一幀，避免並行堆積。速度仍取決於實機。

1. 關閉舊網站分頁，再重新開啟正式網站。登入狀態失效才需要自己的個人金鑰；受邀方使用完整新邀請。
2. 開啟鏡頭，先確認有正在更新的影像，再選「物件」。首次使用需等待模型下載及啟動。
3. 對準桌上的杯子、鍵盤或其他一般物件，查看是否出現辨識結果。沒有目標時可顯示未偵測到，而不是啟動錯誤。
4. 再測試「人臉」，確認有位置框；不會辨識個人身份。
5. 若仍出錯，記錄 iPad 型號、iPadOS 版本、瀏覽器及完整錯誤畫面。可另用 Safari 測試來比較；不能以換瀏覽器代替正式驗收。

此修正針對物件／人臉分析，不代表 iPad 支援 Wonderland 的沉浸式 WebXR AR。47 項程式測試及桌面真實 MediaPipe 物件／人臉模型回歸測試通過（各處理 4 幀，套用正式 CSP）；尚未在第 9 代 iPad、iPadOS 27.0 Chrome 上完成實機驗證。
