# 使用與測試

## 使用已部署網站

1. 開啟 https://visionlink-hk.visionlink-workspace.workers.dev/login/ 。
2. 首次使用按「首次使用？免費建立帳戶」，輸入顯示名稱。
3. 保存只顯示一次的個人金鑰，再進入工作空間。日後登入需要這個金鑰，沒有電郵找回功能。
4. 「連接協作夥伴」→「建立房間」→私下複製完整房間邀請。
5. 另一台裝置開啟邀請，按「加入房間」，不需註冊或共用你的金鑰。
6. 兩邊按「開啟鏡頭」，需要語音時另外按「開啟收音」。在現場視角／夥伴視角間切換。
7. 輸入預期貨號，對準條碼或 QR，確認比對結果，再人工勾選包裝及數量清單。
8. 點畫面標記、新增協作指令，確認另一邊同步看到。登入者可儲存自己的紀錄；訪客可匯出本次紀錄。
9. 最後按「結束連線」，關閉鏡頭及收音。

房間限兩人、一小時。自行註冊每個網絡每 UTC 日最多 3 個名額、整站每日 100 個。GitHub 登入不等於網站登入；金鑰與有效邀請不能放在 GitHub。

## 不用準備資料的示範

1. 在「貨號／設備資料」選 VL-2048、A102（Motor A）、V003（Valve 03）或 VL-2051。
2. 按「載入示範 QR 照片」。本機 ZXing 真正讀取 QR，應顯示「貨號相符」與資料卡；不會自動勾選驗收。
3. 卡片的庫存、位置及維修紀錄都是虛構示範。選「用名稱作文字標籤」，再點畫面放置名稱。
4. 選箭頭／圈選／畫線，輸入「這裡拆」或「檢查接線」並拖曳；文字只需點一下。可暫停畫面、撤回或清除。
5. 兩人連線後，遠端切換到「夥伴視角」再標記；現場應同步看見文字及形狀。未收錄貨號顯示「尚未建立資料」。
6. 日後在「替換為自己的資料」下載範例或匯入 JSON。只在本次頁面載入；巡檢紀錄保存已選卡片，未連接共用庫存系統。

## Android AR 文字與圖形

1. 使用支援 WebXR 的 Android Chrome；電腦通常只能看 3D 預覽。
2. 按「3D / AR」再按「進入 AR」。確認標示「AR 已啟動 · 真實環境」，並看到真實鏡頭背景。
3. 對準光線充足、有紋理的桌面，慢慢移動手機，等待黃色瞄準球。
4. 按一次「設定工作區」，確認出現「工作區已設定」。
5. 選文字並輸入名稱，對準位置按「放置文字標籤」。箭頭／圈選依序確認起點與終點；畫線沿表面逐點記錄後按「完成畫線」。移動手機，文字及圖形應留在同一實體位置。
6. 要雙端精細對齊時才開啟「進階：雙端三點對齊」，兩邊用同一套 O/X/Z 布局。

黃色球目前分別表示移動的瞄準位置、固定的參考原點及人工新增的檢查標記。它們不是 AI 損傷判斷。AR 標記記錄空間位置；一般現場畫面標記記錄影像上的位置。簡易工作區的方向由手機朝向建立，不會自動對齊兩個不同地點。

遠端在夥伴視角繪製指令後按「固定到實物（AR）」；現場開啟 AR、設定工作區、對準實物位置並按「固定這個指令」。箭頭末端固定在確認點，形狀約 25 公分，須人工核對。設備移動後重放；一般影片或暫停畫面上的圖形不會自動追蹤實物。桌面可按「示範 AR 標籤」查看圖形及中文文字，這仍是 3D 示範。

損傷模式自動在中央檢查範圍顯示紅框與「疑似…／需覆核」；這是區域分類，沒有精確裂痕位置。取得疑似結果後可按「將疑似損傷交給現場 AR 確認」，定位仍由現場確認。

## 建議最小驗收

| 測試 | 預期 |
| --- | --- |
| 新帳戶建立房間 | 可產生有效邀請 |
| 另一台未登入裝置加入 | 不要求個人金鑰 |
| 兩邊影音／指令／清單 | 同步可見及可聽 |
| QR 貨號核對 | 與訂單字串精確比對 |
| 他人私人紀錄 | 無法讀取或覆寫 |
| AR 空間標記 | 手機移動後仍留在原實體位置 |
| 結束或過期房間 | 邀請不能繼續加入 |

目前未完成香港跨網絡影音與 AR 漂移精度的正式實機驗收，不能只以桌面測試代替。
