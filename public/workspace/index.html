從資料到驗收，五個步驟。

  1. 1. 準備你的貨品資料

    登入後按「管理貨品 · 新增／匯入」。少量貨品直接填表；Excel 資料連同欄名一起複製，在「匯入／貼上表格」貼上，或選 CSV UTF-8 檔案。指定貨號及名稱欄，預覽新增／更新筆數後確認。資料儲存在你的帳戶，同帳戶可跨裝置讀取。示範資料在「練習與備份」內，與正式資料分開。

  2. 2. 開始一次驗收

    先到「巡檢紀錄」按「開始新驗收紀錄」。選擇貨品並按「設為預期貨號」，開啟鏡頭或載入貨品照片。在「貨號」模式掃描實物條碼／QR Code，檢查比對結果和貨品資料卡。普通印刷文字不會自動當作條碼讀取。

  3. 3. 邀請夥伴共同檢查

    按「連接協作夥伴」→「建立房間」→複製完整邀請連結。對方免登入，開啟後按「加入房間」。遠端切到「夥伴視角」，可用箭頭、圈選、畫線及文字提出檢查指令；需要仔細畫圖時先暫停畫面。房間一小時有效。

  4. 4. 需要固定在實物上時才使用 AR

    現場用支援 WebXR 的 Android Chrome 進入 AR。慢慢移動手機，等到平面定位提示後設定工作區，再選文字／箭頭／圈選／畫線。收到遠端指令時，對準實物按「固定這個指令」。移動手機確認標記仍留在原處；普通視訊標記會跟畫面走，兩者不同。AR 鏡頭共享需裝置額外支援。

  5. 5. 覆核、記錄與交接

    逐項人工核對貨號、外箱及數量，輸入協作備註，按「儲存驗收紀錄」，確認顯示「已儲存」。可下載 CSV 摘要交接，完整資料另有 JSON 備份。照片不存到雲端，需要留證請另按「擷取畫面」。完成後結束房間；下一箱先開始新紀錄。庫存數字需在貨品編輯中更新，掃描和驗收不會自動增減庫存。

使用 localhost 或 HTTPS 才能取得鏡頭；手機請使用 HTTPS 網址。損傷試驗模式分類中央疑似損傷區域：撕裂、壓凹、膠帶、包膜。模型不會證明外箱正常，須人工覆核；人臉偵測不會辨識身份。
