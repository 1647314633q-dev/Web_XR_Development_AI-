讓協作開始，四個步驟。

  1. 探索示範場景

    點擊畫面新增標記，完成驗收清單，輸入指令及匯出 JSON 紀錄。

  2. 開啟真實鏡頭

    允許瀏覽器存取鏡頭。物件／人臉使用 MediaPipe 在本機偵測；貨號模式使用本機 ZXing 讀取條碼／QR Code，與輸入的訂單貨號作精確比對；不提供 OCR。

  3. 連接另一位夥伴

    透過「連接協作夥伴」建立房間並分享邀請連結。發起方登入後建立房間；受邀者使用有效連結免登入加入。影像及標記使用 WebRTC，跨網路可能需要 TURN 服務。

  4. 體驗 AR 空間標記

    Wonderland Engine 1.6.1 原生渲染 3D 巡檢場景，支援拖曳旋轉及空間標記同步。支援 immersive-ar 的裝置可進入 AR；預設只需對準桌面並按一次「設定工作區」，再按「＋新增空間標記」標出檢查位置。移動手機時，AR 標記應留在真實空間位置；兩地精細對齊可使用進階三點設定。AR 鏡頭共享需 camera-access；不支援時會明確暫停 AR 影像共享。未提供現場 3D 重建。普通瀏覽器仍可使用鏡頭協作。

使用 localhost 或 HTTPS 才能取得鏡頭；手機請使用 HTTPS 網址。損傷試驗模式分類中央疑似損傷區域：撕裂、壓凹、膠帶、包膜。模型不會證明外箱正常，須人工覆核；人臉偵測不會辨識身份。
